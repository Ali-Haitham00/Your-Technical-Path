اللغات

كورس Python

لغة برمجة سهلة وقوية تُستخدم في تطوير الويب والذكاء الاصطناعي وتحليل البيانات.

كورس Node.js

بيئة تشغيل JavaScript تُستخدم لبناء تطبيقات ويب سريعة وقابلة للتوسع.

كورس JavaScript

لغة وإطار عمل يساعدان على تطوير تطبيقات الويب بسرعة وكفاءة.

كورس Java

لغة برمجة قوية تُستخدم في تطوير تطبيقات الويب والهواتف والأنظمة المختلفة.

كورس C# (ASP.NET)

لغة وإطار عمل من مايكروسوفت لتطوير تطبيقات الويب والبرامج الحديثة.

كورس PHP

لغة برمجة شائعة تُستخدم لإنشاء المواقع والتطبيقات الديناميكية.

المكتبات

كورس Express.js

إطار عمل لـ Node.js يُستخدم لبناء واجهات برمجة التطبيقات (APIs) وتطبيقات الويب بسهولة وسرعة.

كورس Django

إطار عمل خفيف لـ Python يساعد على تطوير مواقع وتطبيقات ويب متكاملة وآمنة بسرعة.

كورس Flask

إطار عمل خفيف لـ Python يُستخدم لإنشاء تطبيقات الويب وواجهات الـ API بمرونة.

كورس FastAPI

إطار عمل حديث لـ Python لبناء APIs سريعة وعالية الأداء.

كورس Laravel

إطار عمل لـ PHP يُسهّل تطوير تطبيقات الويب بطريقة منظمة واحترافية

كورس Spring Boot

إطار عمل لـ Java يُستخدم لبناء تطبيقات الويب والخدمات الخلفية (Backend) بسرعة وكفاءة.
